    MyHub Sheet

    Daily call totals (Date, SIM, Agent Name, Call, Duration, Answered) and the Users tab for login

    Open sheet ↗
    Not connected — showing built-in data
    Refreshes automatically every 20 minutes.
    Sheet check — missing data finder
    Press “Run check” after a sync to see which rows the dashboard could not use, SIMs that carry two names, and agents/dates with no data.

    Bitrix 24 Sheet

    One row per call — Employee, Call duration, Call date, Status. Used by the Bitrix and MyHub vs Bitrix tabs

    Open sheet ↗
    —
    Keep the Call date column as Plain text.

    Callyzer KPI Form Sheet

    Google Form responses — Date, Name, Talk time, WhatsApp Minutes, Dials, Callyzer Screenshot (Drive link), Remarks. Used by the MyHub vs Callyzer tab

    Open sheet ↗
    —
    Talk time column accepts 45m 53s, 45:53 or decimal minutes (45.9) — ask agents to type it exactly as the Callyzer screenshot shows. If the sheet is private (shared only with you), it is read through your Apps Script (ImageProxy.gs) instead — no sharing change needed. Screenshots are read the same way.

    Visits Register Sheet

    Where the Visits tab writes its entries (via the Apps Script). Blank ID in the script = a sheet is created automatically in your Drive on the first entry.

    Open sheet ↗
    —
    Departments shown in the form are set in the file (VISIT_DEPTS) — tell me if the list should change.

    Sales Done Sheet

    Sales records — Sale Date, Salesperson Name, Team Lead, Project, Sqft. Used by the Team Ahsan tab to auto-populate sales (sq ft) instead of manual entry

    Open sheet ↗
    —
    Sheet must have headers: NO, SALE DATE, SALES PERSON'S NAME, SALE'S PERSONS'S TEAM LEAD, CLIENT NAME, PROJECT, FLOOR, UNIT/SHOP, SQFT, TOTAL VALUE, NUMBER OF SALES, TYPE OF SALE, Status of DP. Share as "Anyone with the link → Viewer".

    TL Sales Target Sheet

    Monthly sales value targets per team lead (Month, Name, Value in Rs). Used by Team Ahsan tab for the Sales (Value) columns

    Open sheet ↗
    —
    Sheet must have headers: Month, Name, Value. Share as "Anyone with the link → Viewer".
